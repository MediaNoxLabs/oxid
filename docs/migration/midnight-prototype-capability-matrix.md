# Midnight prototype capability matrix

## Authority and method

This is the current capability-status authority for the reviewed
`MediaNoxLabs/midnight-ledger` Dioxus mobile prototype at immutable commit
[`074b1a4bccbfee1740ee188374b606a022ecef42`](https://github.com/MediaNoxLabs/midnight-ledger/tree/074b1a4bccbfee1740ee188374b606a022ecef42/mobile-bench).
It is an evidence matrix, not a source-line comparison. `Adapted` preserves a
user capability through Oxid-owned ports and adapters; it does not preserve the
prototype implementation.

The source tree was inspected read-only at that exact commit under
`mobile-bench/`, including `wallet-core`, `dioxus-wallet`, `headless-wallet`,
`prover-core`, native hosts, and the protocol/vault surfaces. ADR-0021 remains
the architectural boundary. Historical prose and checkbox states in
[issue #2](https://github.com/MediaNoxLabs/oxid/issues/2) and
[midnight-ledger-prototype.md](midnight-ledger-prototype.md) are provenance,
not status evidence; this matrix and the linked executable evidence supersede
them.

**Delivery notation.** `develop` is this documentation change's delivery base.
Every `Open` row has one existing bounded implementation issue and the exact
functional delivery target `milestone-0.2.0`, established by
[issue #287](https://github.com/MediaNoxLabs/oxid/issues/287). That target is
not a claim that a simulator, fixture, or mock supplies the row's required live
or physical-device evidence.

## Reconciliation outcome

Issue #2 remains the historical parity epic, but its checkbox wording cannot be
used to claim closure: it omits later evidence and leaves some delivered slices
marked open. The migration inventory likewise remains detailed provenance, but
its prose is not a live delivery board. The open work above is deliberately
visible, bounded, and linked; no mock, simulator, headless fixture, or Android
result is substituted for the named live or physical-device evidence.
