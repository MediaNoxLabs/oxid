# Support

Use GitHub issues for reproducible bugs, feature proposals, and documentation
gaps. Include the Oxid revision, operating system, Nix version, relevant command,
and a redacted error message.

Do not post vulnerabilities, wallet secrets, seeds, credential claims, private
identifiers, signing material, or production endpoint credentials in an issue.
Use the private reporting process in `SECURITY.md` for security-sensitive work.

Oxid is pre-release software. The current M0 slice is for architecture and
development evaluation only and must not be used to custody real assets or
credentials.
